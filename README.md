# WORKQR-AI
WORKQR‑AI es una plataforma que permite registrar entradas y salidas de trabajadores mediante el escaneo de códigos QR, calculando automáticamente horas trabajadas, fecha, y estado (Activo/Inactivo).   Integra un backend con FastAPI, una interfaz frontend React/Vite, y módulos de IA para análisis de asistencia.
